# Contributing

1. Fork or branch from `main`.
2. Copy `.env.example` files and start MongoDB.
3. Run `npm install` at the repository root.
4. Keep API changes in `Backend/` and UI changes in `frontend/`.
5. Run `npm test` and `npm run lint` before opening a pull request.
6. Describe the change and how you verified it.

Use clear commit messages that explain why the change exists.
